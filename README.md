Expense Tracker (Трекер расходов)

Автор
Гатина Рузиля Маратовна

Описание
Графическое приложение для учёта личных расходов. Позволяет добавлять траты, фильтровать их по категориям и периодам, а также автоматически подсчитывать сумму за выбранный диапазон. Данные сохраняются в формате JSON и восстанавливаются при следующем запуске.

Возможности
- Валидация ввода (сумма > 0, корректный формат даты ГГГГ-ММ-ДД)
- Добавление расходов в таблицу
- Фильтрация по категории и диапазону дат
- Подсчёт итоговой суммы за отфильтрованный период
- Автоматическое сохранение и загрузка данных через `JSON`
- Чистый, структурированный код с разделением логики и UI
- Покрытие тестами (позитивные, негативные, граничные случаи)

Как запустить
1. Убедитесь, что установлен **Python 3.8+** (требуется только стандартная библиотека `tkinter`).
2. Скачать репозиторий, определить все папки из проекта в какую-то одну и открыть её через любое IDE.
